# 時給計算アプリ

個人用の勤務管理・時給計算デスクトップアプリケーション（Electron + React + TypeScript）

## 概要

このアプリは、以下の機能を提供します：

- **暗号化データ保存**: 4桁PINによるAES-256-GCM暗号化
- **日給計算**: 深夜割増・8時間超割増・土日祝加算の自動計算
- **月次集計**: 出勤日数と月給の自動集計
- **祝日対応**: 年度別祝日マスタファイル対応

## 技術スタック

- **フレームワーク**: Electron 28.x
- **UI**: React 18.x + TypeScript 5.x
- **暗号化**: AES-256-GCM (PBKDF2鍵導出)
- **日付処理**: date-fns
- **ビルドツール**: Webpack 5.x

## 実装済み機能

### コア機能

✅ **データ構造とDB（暗号化ファイル）**
- AES-256-GCM暗号化による安全なデータ保存
- PBKDF2による鍵導出（100,000回反復）
- 自動バックアップ機能（data.enc.bak）

✅ **計算ロジック**
- 日跨ぎ処理（0:00での自動分割）
- 深夜時間帯（22:00〜5:00）の判定と割増（×1.25）
- 8時間超判定（1勤務単位）と割増（×1.25）
- 土日祝加算（+50円）
- 月24日以上加算（+50円、全日適用）
- 休憩時間の除外処理
- 法定休憩チェックと警告

✅ **セキュリティ**
- 4桁PIN認証（SHA-256ハッシュ）
- データ暗号化（PIN認証成功時のみ復号）
- コンテキスト分離（Context Isolation）

✅ **UI基盤**
- PIN認証画面（新規作成/既存ログイン）
- 年度・月選択インターフェース
- データ自動保存

## 計算ロジックの詳細

### 割増計算ルール

```typescript
// 基本時給の決定
hourlyWage = baseWage
if (monthBonus) hourlyWage += 50  // 月24日以上
if (isHoliday) hourlyWage += 50   // 土日祝

// 割増率の適用
if (isNight || isOvertime) rate = 1.25
else rate = 1.0

// 最終時給
finalWage = hourlyWage × rate
```

### 重要な仕様

1. **8時間超判定**: 1勤務単位で判定（日跨ぎでも分割しない）
2. **土日祝加算**: 時間帯ごとに判定（例: 金曜22:00〜土曜10:00の場合、土曜分のみ+50円）
3. **月24日以上加算**: 月末に判定し、該当月の全日給に遡って適用（+50円）

## データファイル

- **保存場所**: `%APPDATA%/nikkyu-keisan/data.enc` (Windows)
- **バックアップ**: `%APPDATA%/nikkyu-keisan/data.enc.bak`
- **形式**: 暗号化JSON

## 祝日マスタ

祝日は`Docs/祝日リスト_YYYY.md`に年度別のMarkdownテーブルとして管理します。

例: `Docs/祝日リスト_2026.md`
```markdown
| 月 | 日 | 祝日名 |
|----|----|---------------------------------|
| 1  | 1  | 元日                            |
| 1  | 13 | 成人の日                        |
```

## 注意事項

- **PINの管理**: PINを忘れるとデータにアクセスできなくなります。必ず安全に保管してください。
- **バックアップ**: 重要なデータは定期的に外部にバックアップすることを推奨します。
- **セキュリティ**: このアプリはローカル専用です。ネットワーク経由でのデータ送信は行いません。
