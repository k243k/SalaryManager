# 時給計算アプリ 詳細設計書（完全版）

## 1. 本書の位置づけ

本書は「時給計算アプリ 要件定義書（完全版）」に基づき、実装者（人／AI）が迷わず実装できることを目的とした詳細設計書である。

## 2. 全体構成設計

### 2.1 アプリ構成（論理）

- 単一ユーザー・単一データ領域
- ローカル完結
- 年度 → 月 → 日 の階層構造

```
年度
 └─ 月（1〜12）
     └─ 日（1〜月末）
         └─ 勤務情報
```

### 2.2 技術スタック（実装方針）

#### 2.2.1 言語・実行環境

- **言語**: TypeScript
- **実行形態**: ローカルデスクトップアプリ（Windows向け）
- **配布物**: 利用者はダブルクリック起動でき、追加の環境構築を不要とする

#### 2.2.2 フレームワーク／UI

- **デスクトップアプリ基盤**: Electron
- **UI**: React（TypeScript）
- UIコンポーネントは必要最小限とし、日次入力が高速に行えることを優先する

#### 2.2.3 データ保存方式

- **保存方式**: 暗号化JSONファイル（単一ファイル）
- **例**: `data.enc`
- データは平文で保存しない（復号はPIN認証後のみ）

#### 2.2.4 暗号・認証

**PIN（4桁）の取り扱い**:

- **PIN検証**: PINハッシュで実施（PIN平文保存は禁止）
- **データ暗号化**: PINから鍵を導出し、JSONを暗号化して保存する
- 鍵導出方式・暗号方式・IV等の詳細は 2.2.5 にて定義する

#### 2.2.5 暗号仕様（詳細）

- **鍵導出**: PBKDF2（salt必須、反復回数は実装時に定数化）
- **暗号方式**: AES-256-GCM

**保存時に保持するメタ情報（例）**:

- `salt`（Base64）
- `iv`（Base64）
- `ciphertext`（Base64）
- `tag`（GCM認証タグ、実装によりciphertextに含まれる場合あり）

ファイルフォーマットはJSONまたはバイナリのいずれかとし、詳細は実装で確定する（互換性維持のため、バージョン番号を持つことが望ましい）。

#### 2.2.6 日付・祝日ライブラリ

- **日付処理**: date-fns
- **祝日判定**:
  - 要件定義上「祝日の自動判定は必須ではない」
  - ただし詳細設計では、拡張に備え**祝日マスタ（年度別JSON）**を読み込める構造を採用する

#### 2.2.7 ビルド／パッケージ

- **パッケージ**: electron-builder
- **生成物**: Windows向け `.exe`（インストーラ型またはポータブル型は実装で選択）

### 4.1 起動画面

- 誤入力時はエラーメッセージ表示
- 認証成功後、メイン画面へ遷移

### 4.2 メイン画面構成

- 年度選択プルダウン
- 月選択タブ（1〜12）
- 月次入力テーブル
- 月給合計表示

### 4.3 月次入力テーブル（1行＝1日）

| 日付 | 出勤 | 開始 | 終了 | 休憩 | 日給 | 警告 |
|------|------|------|------|------|------|------|
| 1 | ☑ | 22:00 | 10:00 | 60分 | ¥13,500 | ⚠ |

## 5. 計算ロジック設計

### 5.1 基本フロー

1. 勤務時間を分単位に変換
2. 日跨ぎの場合、0:00で分割
3. 休憩時間を時間帯別に除外
4. 深夜帯（22:00〜5:00）判定
5. 実働8時間超判定
6. 土日祝判定（曜日／祝日マスタ）
7. 割増・加算を適用
8. 日給算出
9. 月合計へ加算

### 5.2 日跨ぎ処理

- `endTime < startTime` の場合、翌日扱い
- `start → 24:00` と `00:00 → end` に分割
- 日付単位で土日祝判定

### 5.3 休憩処理

- 休憩は時間帯ごとに除外
- 深夜・通常の区分をまたぐ場合は分割
- 実働時間算出後に法定休憩チェック

### 5.4 法定休憩警告ロジック

```javascript
if (actualWork > 8h && break < 60m) → warning
if (actualWork > 6h && break < 45m) → warning
```

※警告は保存・計算を阻害しない

### 5.5 割増の重ね掛けルール（初期仕様）

| 条件 | 適用 |
|------|------|
| 深夜 | +25% |
| 8時間超 | +25% |
| 土日祝 | +50円 |

- 割率は乗算
- 金額加算は時給ベースに加算後、時間計算

### 5.6 月24日以上加算

- 月末または再計算時に判定
- 該当月の全日給計算に反映
- 判定後は即時再計算

## 6. セキュリティ設計

### 6.1 PIN管理

- PINはハッシュ化して保存
- 平文保持禁止

### 6.2 データ保存

- 暗号化ファイルとして保存
- 復号はPIN認証成功後のみ

## 7. エラーハンドリング

| ケース | 挙動 |
|--------|------|
| 開始 > 終了 | 日跨ぎ扱い |
| 休憩 > 実働 | エラー表示・保存不可 |
| PIN誤り | 再入力 |

## 8. 再計算ポリシー

- 入力変更時は該当日＋月を即時再計算
- 年度切替時は再計算不要

## 9. テスト観点（抜粋）

- 日跨ぎ＋深夜＋休日
- 法定休憩未満警告
- 月24日境界（23→24）
- PIN誤入力

## 10. 実装上の注意

- 時刻は必ず分単位で扱う
- 金額は最終表示時に丸める
- 計算途中での丸め禁止
